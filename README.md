# Site Institucional — LIA AGRO

Projeto site institucional da LIA AGRO


## Tecnologias utilizadas

- C#
- ASP.NET Core 8
- Razor Pages
- HTML e CSS
- JavaScript

O desenvolvimento está sendo feito no Visual Studio.

## O que o site possui

- Página inicial com apresentação da empresa
- História e informações institucionais da LIA AGRO
- Página dedicada ao ROCKSIL PLUS
- Página dedicada ao PROTEGO FL
- Fotografias de aplicações e atividades em campo
- Informações de contato e acesso ao WhatsApp
- Layout adaptado para computadores e celulares
- Conteúdo em português, inglês, italiano, espanhol, alemão e francês


## Próximas melhorias

Ainda pretendo adicionar outras funcionalidades e conteúdos ao site, principalmente vídeos de aplicações dos produtos, depoimentos de clientes, mais fotografias e informações técnicas.

Também vou continuar ajustando o visual, revisando as traduções e preparando o projeto para publicação no domínio oficial da empresa.

## Sobre o projeto

O objetivo é manter um site institucional que possa ser atualizado e ampliado conforme as necessidades da LIA AGRO.
